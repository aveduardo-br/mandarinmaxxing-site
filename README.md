# mandarinmaxxing-site

Website for [mandarinmaxxing](https://github.com/aveduardo-br/mandarinmaxxing), a topic-based way to study Mandarin with HSK 3.0 vocabulary and phrases you can use in everyday conversations.

Status: design handed off, build not started yet. See [`HANDOFF.md`](HANDOFF.md).

- `design/screens/`: screenshots of each section from the Paper design
- `prototypes/rising-hanzi-hero.html`: working prototype of the hero animation (open in a browser)
- `assets/fonts/`: Zpix subsets used in the design
- `docs/content-background.md`: product and content notes about the skill
